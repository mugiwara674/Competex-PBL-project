1. Introduction

1.1 Project Overview

CompeteX is a full-stack, centralized competition operating platform designed to manage college-level technical and non-technical competitions. Educational institutions host multiple hackathons, coding contests, quizzes, project expos, and paper presentations throughout the academic year. CompeteX provides an all-in-one digital environment connecting Students, Squads, Event Organizers, Industry Judges, and Campus Administrators.

1.2 Purpose and Objectives

The primary objective of CompeteX is to eliminate operational fragmentation caused by managing competitions through ad-hoc tools like Google Forms, offline spreadsheets, messaging groups, and email threads.

  • Unified Competition Catalog: Single portal for exploring technical hackathons, algorithmic coding, live quizzes, hardware expos, and paper colloquiums.
  • Frictionless Squad Formation: 6-character cryptographic join codes allowing instant team member recruitment within configured caps.
  • Standardized Weighted Evaluations: Multi-criteria rubric scoring forms preventing evaluation bias.
  • Institutional Accreditation Support: 1-click UTF-8 BOM CSV exports tailored for university NAAC and NBA compliance audits.
  • Embedded Sandboxes: Zero-setup algorithmic code execution (JS, Python, C++, Java) and Web Audio synchronized timed quizzes.
  • Verifiable Digital Diplomas: Official digital certificates with public serial lookup and golden foil seals.

2. Project Overview

2.1 Background

In universities, technical and co-curricular events are vital for fostering engineering skills and student employability. However, traditional event workflows rely on manual coordination, spreadsheet tallying, and unverified participation certificates. CompeteX delivers an institutional-grade solution designed to eliminate these inefficiencies.

2.2 Problem Statement

  • Fragmented Tooling: Intake through forms, judging via spreadsheets, and results communicated over emails.
  • Student Friction: Difficulty finding teammates with complementary skills and tracking multiple conflicting deadlines.
  • Judging Inconsistencies: Lack of weighted rubrics leading to manual calculation errors and delayed results.
  • Accreditation Compliance Gaps: Difficulty retrieving historical student achievement data during university audits (NAAC/NBA).

2.3 Solution Architecture

CompeteX provides 14 integrated modules covering every stage of the competition lifecycle:

Module Name Primary Beneficiary Key Functionality
1. Competitions Catalog Students & Organizers Multi-discipline event discovery, search filters, and rule overviews.
2. Algorithmic Code Sandbox Student Coders In-browser code editor with automated assertions in JS, Python, C++, Java.
3. Live Timed Quiz Arena Quiz Participants 20s buzzer countdown, Web Audio API sound synthesis, streak multipliers.
4. Teams & Join Codes Students 6-character cryptographic join codes (e.g., CPX-3304) and roster controls.
5. Multi-Round Submissions Students & Judges Multi-asset intake: GitHub repos, live demo links, slides, and demo videos.
6. Rubric Judging Pad Judges Weighted scoring (Innovation, Execution, Impact, UI Polish, Presentation).
7. Real-Time Leaderboards Public / Campus Podium rankings with Gold/Silver/Bronze trophy badges and tie-breakers.
8. Verifiable Certificates Students & Recruiters Printable diplomas with university crest and public verification codes.
9. Event Timeline Roadmap Participants & Faculty Live countdown ticker (Days:Hours:Mins:Secs) and stage progress cards.
10. Mentorship Helpdesk Squads & Mentors 24/7 support ticketing with priority queues and mentor conversation threads.
11. Accreditation Data Exports Administrators 1-click Excel CSV downloads for NAAC/NBA auditing.
12. Role-Based Auth (RBAC) All Users 1-click role switcher + persistent login/register with password hashing.
13. Project Showcase Gallery Campus Community Public prototype gallery with People's Choice voting and peer reviews.
14. Sponsor Bounties & Logistics Sponsors & Students Cash bounties (Google Cloud, Intel, GitHub, Red Hat) & campus room schedule.

3. System Architecture & Tech Stack

CompeteX utilizes a self-contained, high-performance architecture built exclusively on native Node.js standard libraries (http, fs, path, crypto, vm) without external npm package dependencies, ensuring instant startup, zero vulnerability footprint, and portable execution.

Backend: Native Node.js HTTP & REST Services
Database: Persistent Atomic JSON Store (data/db.json)
Frontend: Vanilla ES6+ Single-Page Application (SPA) with Tailwind CSS
Port & Host: http://localhost:3000

4. Verification & Accreditation Compliance

A standout capability of CompeteX is its direct alignment with National Assessment and Accreditation Council (NAAC) Criterion 5 (Student Support and Progression) and National Board of Accreditation (NBA) criteria. By automating the export of rosters, submissions, rubric audits, and certificate serials into Excel-friendly CSVs with UTF-8 BOM encoding (\uFEFF), administrative overhead during accreditation reviews is reduced to zero.
