## 1. Introduction

### 1.1 Project Overview
**CompeteX** is a centralized, full-stack web application engineered to unify and streamline the administration, participation, and evaluation of technical and non-technical college competitions. Modern educational institutions host numerous hackathons, coding contests, technical quizzes, project exhibitions, and research paper presentations. CompeteX provides a single cohesive digital ecosystem connecting **Students, Teams, Event Organizers, Industry Judges, and Campus Administrators**.

### 1.2 Purpose and Objectives
The primary purpose of CompeteX is to eradicate operational fragmentation caused by juggling disparate tools like Google Forms, offline spreadsheets, messaging applications, and manual emails. 

**Key Objectives:**
* **Centralized Discovery:** Provide an interactive catalog for multi-disciplinary campus competitions.
* **Frictionless Collaboration:** Enable instant squad formation using 6-character cryptographic join codes.
* **Objective Evaluation:** Standardize judging through weighted multi-criteria rubrics.
* **Academic Accreditation:** Generate one-click CSV export datasets for university NAAC and NBA compliance audits.
* **Interactive Sandboxes:** Embed in-browser algorithmic coding and synchronized audio quiz buzzers directly inside the web interface.
* **Verifiable Credentials:** Issue tamper-evident digital certificates with cryptographically verifiable serial numbers.

### 1.3 Target Audience
* **Students / Participants:** Discover events, form teams, submit multi-round projects, take live quizzes, and download verified credentials.
* **Event Organizers:** Host competitions, manage rounds, broadcast notices, review submissions, and publish podium results.
* **Judges / Evaluators:** Access assigned submissions, grade projects using weighted rubrics, and provide private/public feedback.
* **Campus Administrators:** Oversee campus events, audit judge scores, manage users, and export institutional accreditation data.

### 1.4 Document Structure
This documentation follows a comprehensive technical progression, from architectural design and database models to feature walkthroughs, implementation guides, and operational troubleshooting.

## 2. Project Overview

### 2.1 Background
Higher education institutions routinely conduct extracurricular and co-curricular competitions to cultivate technical aptitude, innovation, and leadership among engineering students. However, the operational management of these events is conventionally decentralized and manually intensive, leading to communication delays, lost project submissions, and subjective evaluations.

### 2.2 Problem Statement
Colleges face severe administrative challenges due to:
* **Fragmented Platforms:** Google Forms for intake, WhatsApp for team matching, Discord for announcements, spreadsheets for judging, and emails for certificates.
* **Student Inconvenience:** Inability to find teammates with complementary skill sets, track multiple deadlines, or view live standings.
* **Evaluation Inconsistencies:** Judges grading without clear criteria weights, resulting in scoring bias and calculation errors.
* **Lack of Historical Records:** Difficulties in retrieving past competition rosters and winner data during institutional accreditation audits (NAAC, NBA).

### 2.3 Solution Overview
CompeteX resolves these issues by delivering an integrated, high-performance platform that manages the complete competition lifecycle:
* **Single Sign-On & RBAC:** Customized portals for Students, Organizers, Judges, and Admins.
* **Automated Squad Assembly:** 6-character join keys eliminating manual team registration sheets.
* **Weighted Scoring Engine:** Instant mathematical aggregation across multi-rubric evaluation forms.
* **Digital Certificate Registry:** Public credential verifier verifying tamper-resistant serials.
* **Community Engagement:** Interactive project showcase with People's Choice upvoting and sponsor cash bounties.

### 2.4 Key Features Summary
1. **Multi-Discipline Catalog:** Hackathons, Coding Arena, Quizzes, Project Expos, Paper Presentations.
2. **Algorithmic Code Sandbox:** In-browser execution in JavaScript, Python, C++, and Java.
3. **Timed Quiz Arena:** 20s countdown buzzer with Web Audio API sound synthesis and streak multipliers.
4. **Team Join Codes:** Instant invite codes (e.g. `CPX-3304`).
5. **Multi-Round Submissions:** Multi-link intake (GitHub, live demo, slides, video).
6. **Rubric Judging Pad:** Weighted scoring across 5 standardized criteria.
7. **Live Leaderboards:** Real-time podium standings with Gold/Silver/Bronze trophy badges.
8. **Digital Certificates:** High-res printable diplomas and public verification lookup.
9. **Event Timeline:** Live ticking countdown widget and multi-stage roadmaps.
10. **Mentorship Helpdesk:** 24/7 support ticketing with mentor conversation threads.
11. **Accreditation Data Exports:** 1-click UTF-8 BOM CSV exports for institutional reporting.
12. **Role Switcher & Auth:** Instant role switching + persistent login/register.
13. **Project Showcase:** Community gallery with People's Choice upvoting and peer reviews.
14. **Sponsor Hub & Campus Schedule:** Cash bounties (Google Cloud, Intel, GitHub, Red Hat) and venue locator.

## 3. System Architecture

### 3.1 High-Level Architecture
CompeteX is engineered with a modern, zero-dependency client-server architecture:

```
[ Client Browser (Responsive SPA) ]
       │
       ▼ (HTTP / JSON REST APIs)
[ API Gateway & Router (Node.js Core HTTP) ]
       │
   ┌───┴───────────────────────────────┐
   ▼                                   ▼
[ Domain Logic Controllers ]    [ Persistent Storage Engine ]
  • Auth & RBAC Guards            • JSON Database (data/db.json)
  • Rubric Scoring Engine         • Atomic File Persistence
  • In-Browser Code Sandbox       • UTF-8 BOM CSV Exporter
  • Web Audio Quiz Engine         • Credential Verifier
```

### 3.2 Technology Stack
* **Frontend:** Vanilla JavaScript (ES6+), Tailwind CSS (via CDN), FontAwesome Iconography, Web Audio API.
* **Backend:** Native Node.js (`http`, `fs`, `path`, `url`, `crypto`, `vm`) without external npm dependencies.
* **Database:** Atomized, persistent JSON database (`data/db.json`).
* **Environment:** Node.js Runtime v18+, cross-platform Windows / Linux compatibility.

### 3.3 Frontend Architecture
The client application is built as a Single-Page Application (SPA) inside `public/index.html` and `public/js/app.js`:
* **State Management:** Centralized reactive `state` object holding current user, competitions, teams, submissions, evaluations, tickets, sponsors, and sandbox states.
* **View Router:** Modular switch-based router toggling visibility among 14 distinct functional panels (`#view-competitions`, `#view-coding`, `#view-quiz`, `#view-teams`, `#view-submissions`, `#view-judging`, `#view-leaderboard`, `#view-certificates`, `#view-announcements`, `#view-timeline`, `#view-helpdesk`, `#view-showcase`, `#view-sponsors`, `#view-admin`).
* **Interactive Modals:** Lightweight dialogs for authentication, competition creation, squad management, submissions, certificate viewing, mentorship tickets, and project feedback.

### 3.4 Backend Services & API Gateway
The backend server (`server.js`) utilizes Node.js standard modules to handle routing, request parsing, authentication verification, and data persistence:
* **JSON Body Parser:** Reads asynchronous request streams with UTF-8 chunk buffering.
* **Static File Server:** Streams HTML, JavaScript, CSS, and asset files with correct MIME headers.
* **CSV Streaming Engine:** Formats database collections into Excel-compatible CSVs with UTF-8 BOM (`\uFEFF`).

## 4. Features and Functionality

### 4.1 Role-Based Access Control (RBAC) & Authentication
CompeteX defines four distinct user personas:
* **Student:** Register, create/join squads, submit deliverables, take quizzes, code in sandbox, upvote projects, download certificates.
* **Organizer:** Host events, manage submission deadlines, broadcast notices, review mentorship tickets, issue certificates.
* **Judge:** Access assigned submissions, grade projects with weighted rubrics, provide feedback.
* **Administrator:** Oversee all campus competitions, audit scores, manage users, download accreditation CSVs.

A **Quick 1-Click Role Switcher** is embedded in the top navbar to instantly test different viewpoints during live demonstrations.

### 4.2 User Profile Management
Users maintain persistent profiles with legal name, college/department, avatar icon, primary technical skills, and participation history.

### 4.3 Multi-Disciplinary Competition Catalog & Discovery
Displays ongoing and upcoming competitions across five categories:
* **HackSprint 2026** (Flagship Hackathon)
* **CodeCraft Arena** (Algorithmic Coding)
* **BrainByte Arena** (Technical Quiz)
* **TechExpo 2026** (Hardware & IoT Expo)
* **IEEE Synapse** (Research Paper Presentation)

### 4.4 Squad Formation & Cryptographic Join Codes
Students can create a team and receive a unique 6-character squad join code (e.g., `CPX-3304`). Teammates simply enter the code to join the squad, automatically validated against minimum and maximum team constraints.

### 4.5 Multi-Round Submission Engine
Supports multi-asset submissions including:
* GitHub Repository URL
* Live Cloud Demo URL
* Architecture Presentation Slide Deck
* 2-Minute Walkthrough Video Link
* Key Technology Tags

### 4.6 Weighted Rubric Judging Pad
Judges score submissions against five weighted criteria:
1. **Innovation & Originality** (25%)
2. **Technical Execution & Architecture** (25%)
3. **Real-world Viability & Impact** (20%)
4. **UI / UX Polish** (15%)
5. **Pitch & Presentation Clarity** (15%)

Total scores are calculated automatically with score normalization and recorded to the database.

### 4.7 Real-Time Leaderboards & Dynamic Podium
Displays interactive podium standings with Gold, Silver, and Bronze trophy honors, total scores, member counts, and project links.

### 4.8 Tamper-Evident Digital Certificates & Public Verifier
Issues verifiable credentials featuring university crests, gold foil seals, faculty signatures, and unique verification codes (e.g. `VFY-8921-9402`). A public verifier enables recruiters to validate authenticity.

### 4.9 Algorithmic Coding Sandbox (CodeCraft)
In-browser coding challenge arena with syntax highlighting, starter boilerplates, test-case assertion runners, and time/memory execution telemetry for JavaScript, Python, C++, and Java.

### 4.10 Timed Live Quiz Arena (BrainByte)
20-second countdown buzzer per question with synchronized audio synthesis (ticks, correct chimes, buzzer sounds) via the Web Audio API, dynamic streak multipliers, and instant rationale explanations.

### 4.11 Milestone Countdown Roadmap & Timeline
Displays an active countdown clock (`Days : Hours : Mins : Secs`) targeting the nearest upcoming deadline alongside stage cards (`Completed`, `Active`, `Upcoming`).

### 4.12 24/7 Mentorship & Helpdesk Ticket Hub
Ticketing hub categorized by Technical/Code, Hardware Kits, Mentorship, and Rules. Supports priority levels and multi-turn mentor reply threads.

### 4.13 Public Project Showcase & People's Choice Voting
Public project gallery featuring cover banners, tech stacks, deliverable links, and **People's Choice upvoting** with community peer feedback threads.

### 4.14 Sponsor Bounties & Campus Logistics Hub
Features cash bounties from tech partners (**Google Cloud, Intel, GitHub, Red Hat**) and a chronological campus venue schedule mapping room allocations (`AUD-B`, `LAB-204`, `HW-LAB-3`).

### 4.15 Institutional Accreditation & 1-Click CSV Exports
Generates five audit-ready CSV exports formatted with UTF-8 BOM (`\uFEFF`) for university NAAC and NBA documentation.

## 5. Database Design

### 5.1 Database Overview
CompeteX uses an atomized, persistent JSON database located at `data/db.json`. It guarantees atomic file writing to prevent race conditions during concurrent user operations.

### 5.2 Collections Structure
The database maintains the following primary collections:
* `users`: Registered user accounts and role profiles.
* `competitions`: Event details, category, formats, deadlines, rounds, and rubrics.
* `teams`: Registered squads, join codes, leadership, and member rosters.
* `submissions`: Multi-round project deliverables and tech stacks.
* `evaluations`: Granular criteria scores, private remarks, and public feedback.
* `certificates`: Issued credentials, serial numbers, and verification codes.
* `tickets`: Mentorship tickets, priority levels, and reply threads.
* `sponsors`: Partner tiers, perks, and prize bounty challenges.
* `schedules`: Campus agenda items, locations, room codes, and session status.

## 6. API and Data Flow

### 6.1 RESTful API Architecture
CompeteX exposes standardized REST endpoints over HTTP:

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| **GET / POST** | `/api/auth/login` | User authentication and session token verification |
| **POST** | `/api/auth/register` | New user account creation in database |
